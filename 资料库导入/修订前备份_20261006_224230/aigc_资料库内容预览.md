3. 接口化改造：从双账号数据导出切入，将多浏览器登录、账号切换与手动排队下载整合为桌面工具；通过后台业务接口获取数据，并将人工下载与工具输出逐项对照验证。大体量导出环节由约 1–2 小时缩短至约半小时。
4. 全链路构建：通过 Agent 辅助开发实现素材下载、跨表数据匹配、自动标注、结果整理及审核送审 5 个核心环节，串联 4 个业务平台；优先使用 API，对无合适接口的页面采用 Playwright 或基础 RPA。
5. 模块化工具后端：将自研业务功能与 Python 脚本整理为 36 个启用业务脚本，通过 MCP 向 ZTT Code 提供统一调用入口；工具后端负责确定性执行，Agent 客户端负责模型判断与任务编排。36 是业务脚本数量，不与其他检索或管理工具混算。
6. 经验结构化：与素材管理、达人运营和媒介协同，将常见素材配套关系、文件名与 Excel 字段判断依据、Brief、标签标准和边界案例转为 Prompt、规则文档及可复用 Skill，而非开展模型微调。
7. RAG 与项目隔离：借助 Agent 完成文档切分、Embedding 与向量检索，按项目隔离规则知识；Agent 运行时检索对应规则并保留来源。新规则更新知识库即可适配，无需重新修改主业务流程。
8. 混合执行与质量兜底：规则明确的任务优先用确定性程序；规则未命中、多标签冲突或低置信度情况进入模型判断或人工处理。通过人工已匹配样本对照、随机抽检及审核反馈回溯，持续调整规则与 Prompt。
9. 可靠运行与推广：完善自动重试、断点续跑、运行状态提示、输出结果检查和人工处理入口；提供内置规则、操作教程并现场排查启动环境、账号登录态等问题，使小组成员可以独立使用。
10. 送审链路升级：将早期逐批 RPA 送审改为 API 接口化，该环节单次约 2–3 小时缩短至约 5 分钟。该指标仅指批量送审，不与素材下载或全流程时长混用。
11. 成果与验证：同范围的下载、标注、整理和送审任务，单人纯人工基线约 500 条/日，自动化日常约 6000+ 条/日，处理产能约为原基线 12 倍。
12. 成果与验证：峰值处理 1 万+ 条/日、累计处理 30 万+ 条；完整日常任务全流程约 1.5 小时，人工操作低于 5 分钟。
13. 成果与验证：通过随机人工抽检、误判回溯与规则迭代，判断准确率由首版约 70% 提升并稳定在 90%+。
14. 成果与验证：投入 3–5 人业务小组日常生产，支撑 5+ 真实项目，释放产能承接约 3 个新增项目。

### AIGC 视频与音画内容创作

起点待确认 - 终点待确认｜创意策划｜独立创作

1. 综合 AIGC 创作实践：以产品表达、动画叙事和程序化动效为不同创作方法，单个视频和歌曲作为作品案例，不逐个拆成项目。品牌题材属于自主概念创作。

1. 产品卖点转译：以《一颗主摄》为例，将光圈结构、拍摄参数和夜景效果组织为约 87 秒产品短片，用画面对照解释技术信息；《瑞幸生椰拿铁》以约 30 秒时长组织饮品呈现和广告表达。
2. 视觉叙事与连续性：在《最后一块饼干》中将四段素材串联为约 60 秒故事，围绕争抢、意外、机器人引导和共同分享建立情节推进；通过角色、环境、镜头与动作衔接保持连续观看体验。
3. 品牌场景与系列表达：创作 MORI DAY、Maison Caramel 等 Q 版概念短片，将产品形象和角色行为结合；在喜茶动态海报中保留静态产品版式，通过关键帧与饮品元素运动形成动态视觉表达。
4. 程序化动效：基于日常 After Effects 经验负责《只写代码》的创意与脚本，借助 Agent 生成 JavaScript 动画并渲染视频，约 1 小时完成多物体、不同动画及转场的 AE 风格成片。该方式区别于直接调用视频生成模型。
5. 音画协同：结合生成式音乐与视频节奏组织内容，网站展示《今天也在学习你呀》《AI 今天也上线啦》《还在生成》及 Popup；同名 AMV 对应歌曲，Popup 为约 30 秒 BGM。
6. 方法选择与后期判断：结合 Pavo AI、Seedance、Veo、MiniMax 等使用经验与传统剪辑能力，根据画面目标选择模型生成、程序化动画及后期处理，重点关注表达清楚、镜头衔接和音画关系。
7. 成果与验证：形成可在作品集完整查看的产品概念短片、动画叙事、程序化动效及音频作品。
8. 成果与验证：代表成片体现技术信息解释、连续叙事和动效实现三类能力，不以单个视频数量代替项目成果。

### 视频创作工具链与 AgentCut 人机共用剪辑台

2026.05 - 2026.10｜独立需求设计与工具开发

1. 围绕个人视频创作中的素材获取、音频处理和剪辑需求持续构建工具链；多个小工具作为同一生产流程的组件，AgentCut 为其中完整剪辑产品。

1. 素材准备：自研素材搜索／下载器聚合八个素材来源，在统一桌面界面内完成关键词检索、缩略图浏览、预览与批量下载，减少跨站切换。
2. 媒体解析：清影下载器结合 yt-dlp、gallery-dl 与 FFmpeg 完成来源识别、视频／音频格式选择及合并保存；具体可用性受来源权限和平台状态影响。
3. 音频与补帧：声析支持从视频或音频中分离人声和音乐；FrameBoost 实现补帧质量档位、队列、色彩元数据处理、音画同步及硬件回退，满足素材处理与后期准备需求。
4. 识别传统剪辑软件缺少稳定 Agent 操作接口的问题，独立构建人和 Agent 共用同一时间线的本地剪辑产品，以 Electron / React 桌面端配合 Python、FFmpeg 引擎及 HTTP / MCP。
5. 统一界面与 Agent 的批命令语义，采用原子事务、request_id 幂等回执、expected_revision 校验及 dry-run，防止重复提交和并发覆盖。
6. 实现真实素材探测、时间线拖拽与修剪、分割、关键帧、曲线变速、字幕导入、转场、遮罩及嵌套合成；素材与工程按统一契约管理。
7. 支持每通道曲线、白平衡、RGB 增益和串行调色节点；以同源参数驱动预览与 FFmpeg 导出，并通过真实像素、时长和音画同步验证，而非只检查界面。
8. 实现 EBU R128 响度检测与统一、静音检测去空白、配乐自动闪避、代理回放和缓存配额；按场景改善口播及多素材制作效率。
9. 渲染绑定固定版本并进入持久任务队列，支持取消、多画幅批量交付、历史快照恢复和素材工程打包；已交付可运行桌面程序。
10. 流程连接：以实际创作需求拆解功能、借助 Agent 开发并测试，将素材准备与后期编辑能力开放为可调用工具，为个人 Agent 的自然语言执行提供基础。
11. 成果与验证：形成持续使用的个人素材处理工具与可运行的 AgentCut 桌面软件。
12. 成果与验证：素材获取、媒体处理和剪辑能力以完整生产链展示，不将每个单一工具重复列作项目，也不将综合起点当成每个软件的单独开发日期。
