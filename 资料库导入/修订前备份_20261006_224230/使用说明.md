# 网申资料库

1. 本次是精选项目的详细岗位资料库，不是项目清单或三份一页简历。AI 应用保留 5 个完整项目，AIGC 与 AI 运营各保留 4 个；同一体系中的视频、海报及小工具作为项目案例／组件，内容仍详细展开。
2. 在插件“资料”页可选 AI 应用、AIGC 或 AI 运营三个库。对应的 Agent／AI 解决方案、AI 产品等方向已设置映射；原默认资料库保留，未删除。
3. 每个库均包括三段实习、两段校园经历、岗位技能、自我介绍、个人优势及职业规划。项目与经历分别填写短、中、长描述，并拆出背景、职责、工作内容、成果及岗位表达；多段正文采用 1、2、3、4 编号。
4. 单岗位 JSON 可通过插件原有“导入 JSON”入口重新导入。三岗位合并包用于本次批量导入桥接，不要将合并包当作单 Profile 粘入原有单库导入框。
5. 日期不确定的创作子作品和提案保留空白或年度精度。生日、微信、详细地址、政治面貌、紧急联系人、具体到岗时间与异地／加班偏好等未确认字段不代填。
6. 原资料存储已在导入前原样备份到本目录，并另保存在插件本地备份键。导入完成回执包含实际保存后读回的数据，校验报告验证结构、方向选库与编号格式。
7. 网申页面可能限制文本长度或条目数量，应按具体岗位选择最相关项目；库里项目多，不代表要将每个项目都填入每一次申请。提交前仍需检查日期、岗位要求和敏感字段，插件不会自动提交。
