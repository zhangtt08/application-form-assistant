4. AgentCut 人机协作：构建人工与 Agent 共用时间线的剪辑软件，支持素材探测、修剪与分割、关键帧、曲线变速、字幕导入、转场、遮罩和嵌套合成，并开放 HTTP / MCP 工具入口。
5. 后期与交付能力：支持基础调色、响度统一、静音去空白和配乐闪避；连接预览、渲染队列、多画幅导出及工程打包，验证实际视频时长、画面和音画同步。
6. 个人生产工具化：将真实创作中的高频操作转化为桌面功能与 Agent 可调用接口，使素材准备、媒体处理及后期交付能够复用并持续迭代。
7. 项目成果：形成实际使用的素材处理工具链及可运行 AgentCut 桌面程序，覆盖创作前期准备、媒体处理、时间线编辑和成片导出。
